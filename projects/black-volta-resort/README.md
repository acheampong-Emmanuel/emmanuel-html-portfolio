# Black Volta client presentation

Open `index.html` in a modern browser. Keep the `assets` folder beside it. The page also works through a local or hosted static web server.

This directory is the portfolio copy of the static presentation. Open `index.html` from the project link or through a static web server.

The site uses the project's own architectural renders. The hero slideshow uses optimized copies of `1_3 - Photo.jpg`, `1_16 - Photo.jpg`, `1_4 - Photo.jpg`, `1_18 - Photo.jpg` and `1_11 - Photo.jpg`, in that order. The aerial, lodge, pool, courtyard, facade and terrace images come from the same render set. The eight conceptual sketch plates come from PDF pages 2–9 and retain the original design annotations. The Astrix wordmark was copied from an existing studio presentation.

The site and floor drawings in `assets/*-plan.jpg` are high-resolution crops rendered directly from `../Presentation/Black Volta Resort.pdf` at 125 DPI: PDF page 10 for the site and pages 12–15 for ground through third floor. Cropping removes the surrounding page and most plate headings; the drawing, linework, labels and colours are otherwise unchanged. `assets/basement-plan.jpg` is cropped from the basement parking screen capture provided during review. It is lower resolution than the PDF plans; replace it if the original basement drawing becomes available. The basement is a separate tab before the ground and upper floors. The plan viewer initially fits each plate to the window. Use +/− (or the buttons), 0/Fit to reset, then drag with a mouse or scroll/swipe on touch to inspect details. “Open full-size drawing” opens the JPEG on its own.

The **All renders** section includes all 19 files found in `../Renders`, numbered `1_1`–`1_5` and `1_7`–`1_20` in source order. There is no `1_6 - Photo.jpg` in the source folder. Each `1_N - Photo.jpg` maps to `assets/render-NN.jpg` and `assets/render-NN-t.jpg` (optimized full view and thumbnail). The labels are scene descriptions; the original render numbers remain visible on the cards and in the viewer.

The first architecture panel uses `1_12 - Photo.jpg` for its pool-court facade view; the third uses `1_17 - Photo.jpg` for its dusk entrance facade view. Both desktop and phone layouts use these images.

The visual tour is a sequence of still renders. Chapter 01, “The approach,” uses `1_2 - Photo.jpg` at the main entrance canopy; `1_4 - Photo.jpg` is the side view beneath that canopy. There was no finished film file in the project folder. Contact buttons use return links because the PDF contains no verified contact details; the `CONTACT` object near the end of `index.html` can be filled when those are supplied. No suite sizes, room counts or prices were added because the source PDF did not state reliable figures.

Content references: resort concept and river narrative, PDF pages 20–22; site layout and courts, page 10; ground-floor uses, page 12; guest suites and balconies, pages 13–15; rooftop lounge, gym and infinity pool, page 15. The basement image comes from the review screenshot, not the PDF's page 11 block plan.

This is a concept presentation. The plans and visualisations should be checked against final design documentation before external publication.
